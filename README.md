A modern and responsive **Fitness Trainer Website** built to help personal trainers, gyms, and fitness coaches establish a professional online presence. The project includes a powerful **Admin Panel** for managing website content, fitness packages, client transformations, testimonials, and contact inquiries.

## 🚀 Live Features

### 🌐 User Website

* Modern responsive landing page
* Hero section with call-to-action
* About trainer section
* Training programs & packages
* Client transformation gallery
* Testimonials section
* Contact form
* Mobile-friendly design
* Smooth scrolling and animations

### 🔐 Admin Panel

* Secure Admin Login
* Dashboard with analytics
* Manage Training Packages
* Add, Edit & Delete Packages
* Manage Client Transformations
* Upload Before & After Images
* Manage Testimonials
* Manage Contact Messages
* Manage Website Content
* Image Upload Management

## ⚙️ Installation

### 1. Clone Repository

```bash

```

---

### 2. Navigate to Project

```bash
cd FitPro-Trainer-Website-Updated-version-with-admin-panel
```

---

## Backend Setup

```bash
cd backend
```

Install dependencies

```bash
composer install
```

Create environment file

```bash
cp .env.example .env
```

Generate application key

```bash
php artisan key:generate
```

Configure your MySQL database in `.env`.

Run migrations

```bash
php artisan migrate
```

Start Laravel server

```bash
php artisan serve
```

---

## Frontend Setup

```bash
cd frontend
```

Install packages

```bash
npm install
```

Run development server

```bash
npm run dev
```

---

## Database

Configure the following in your `.env` file.

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=fitpro
DB_USERNAME=root
DB_PASSWORD=
```
